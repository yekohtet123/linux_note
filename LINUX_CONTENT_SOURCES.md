# Linux content expansion

Added 7 chapters / 21 original Burmese-language notes on boot/systemd, networking diagnostics, storage, security, Bash automation, performance and practical labs. Existing chapters and notes preserved.

## Research references
- Linux Upskill Challenge: https://github.com/livialima/linuxupskillchallenge
- The Art of Command Line: https://github.com/jlevy/the-art-of-command-line

These sources informed the topic selection. The new Burmese explanations and example command descriptions are original, not copied from these repositories. Commands may vary by distribution, installation, permissions and system configuration. Test in a VM before applying to production.

## Update instructions
- Flutter Android: `flutter pub get` then `flutter build apk --release`
- Flutter Web: `flutter create --platforms=web .` then `flutter build web --release --base-href "/linux_note/"`
- Publish the new build/web directory to the gh-pages branch.
